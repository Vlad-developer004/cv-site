# Security Policy

This is a personal portfolio site with no user accounts, no database, and no
processing of sensitive data beyond an optional contact form (see the
[privacy policy](https://vt-cv-site.vercel.app/de/datenschutz) for details on
what that form does). The attack surface is intentionally small, but reports
are still welcome.

## Reporting a Vulnerability

If you find a security issue (e.g. an XSS vector, a CSP bypass, exposed
secrets, or an auth/data-handling flaw in one of the other projects linked
from this site), please report it privately rather than opening a public
issue:

- Email: terehovvlad29@gmail.com
- See also: [`/.well-known/security.txt`](public/.well-known/security.txt)

I'll acknowledge reports within a few days and aim to fix confirmed issues
promptly. There's no bug bounty — this is a personal project — but I'm happy
to credit reporters if they'd like.
